# Hệ thống quản lý giao hàng

Đồ án môn Công nghệ phần mềm nâng cao: website quản lý giao hàng dự kiến xây dựng bằng ASP.NET Core 8 (MVC + Web API), MySQL 8 và Entity Framework Core (Pomelo).

## Trạng thái
Dự án đang ở giai đoạn lập kế hoạch. Repository hiện chứa tài liệu quản lý dự án, chưa có mã nguồn.

## Công nghệ dự kiến
ASP.NET Core 8 · MySQL 8 + EF Core (Pomelo) · ASP.NET Core Identity · Bootstrap 5 · Leaflet/OpenStreetMap · SignalR · VNPay Sandbox

## Tài liệu
- `docs/` - Product Backlog, kế hoạch dự án (WBS, Gantt, burndown), quy trình làm việc.

## Quản lý dự án (Scrum trên GitHub)
- Mỗi **Sprint** là một Milestone (14 ngày): 6 sprint, 27 story, 106 điểm.
- Mỗi **story** (PB01-PB27) là một Issue, gán label: `status: New / In progress / Done`, `points: 3 / 5 / 8`, `priority: Must / Should / Could`, `bug`.
- Công việc thiết lập repository là issue `SETUP` (0 điểm).
- Mỗi tính năng làm trên một nhánh, gộp vào `main` bằng Pull Request có dòng `Solve #<số issue>`.
